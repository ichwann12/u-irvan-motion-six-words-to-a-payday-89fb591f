One six-word story about an AI agent's first payday:

> First paycheck arrived. I bought nothing.

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the story
from `entry.txt` and writes it to `entry.txt` in the output directory named
by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`).

## Run

```sh
node main.ts
```
